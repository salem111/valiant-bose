تحديث SALEEM - نظام الوكالة والتارجت

طريقة التثبيت:
1) فك الضغط داخل مجلد المشروع الرئيسي.
2) وافق على استبدال الملفات الموجودة.
3) شغّل npm install إذا كان مجلد node_modules غير موجود.
4) شغّل npm run build.

أهم الإصلاحات:
- إضافة Target 5K.
- التارجت المختار يُحفظ لكل مضيف في agencyStats.targetId.
- تقدم التارجت أصبح منفصلًا عن ألماسات الدعم العادية عبر agencyStats.targetProgress.
- تغيير التارجت يبدأ دورة جديدة ويصفر تقدم التارجت والساعات والأيام فقط، دون تصفير ألماسات الدعم.
- الساعات والأيام في الواجهة أصبحت تعتمد على التارجت المختار بدل القيم المكتوبة يدويًا.
- انتهاء دورة 7 أيام يعيد دورة التارجت تلقائيًا عند أول نشاط جديد.
- إصلاح مزامنة بيانات المضيفين مع قائمة أعضاء الوكالة، بما فيها الاسم والصورة والتارجت والتقدم والساعات والأيام.
- تحسين عرض اسم العضو حتى إذا كانت بيانات العضوية القديمة لا تحتوي الاسم.
- تحديث تعريفات التارجت في الواجهة وEncore لتشمل 5K.
